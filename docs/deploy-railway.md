# Как запустить DocScan на Railway

Railway сам соберёт проект и выдаст ссылку вида `https://docscan-production.up.railway.app`. Серверной части у DocScan нет: Railway только раздаёт файлы сайта, а распознавание и PDF делаются в браузере пользователя. Фото на сервер не попадает.

Всё нужное для Railway уже лежит в проекте:

- `Dockerfile` — рецепт сборки: ставит зависимости, скачивает модели распознавания, собирает сайт;
- `Caddyfile` — настройки веб-сервера, который раздаёт готовый сайт;
- `.dockerignore` — что не отправлять на сборку.

Ничего в них менять не нужно.

Есть два способа. **Способ 1 (через GitHub)** удобнее: после настройки каждый `git push` сам обновляет сайт. **Способ 2 (из терминала)** быстрее, если GitHub не нужен.

---

## Способ 1. Через GitHub (рекомендуется)

### Шаг 1. Загрузите проект на GitHub

1. Зайдите на [github.com/new](https://github.com/new).
2. В поле **Repository name** введите `docscan`.
3. Выберите **Private** (закрытый репозиторий: код увидите только вы).
4. Галочки «Add a README», «.gitignore», «license» **не ставьте** — в проекте они уже есть.
5. Нажмите **Create repository**.
6. GitHub покажет страницу с командами. Вам нужен адрес репозитория вида `https://github.com/ВАШ_ЛОГИН/docscan.git`.
7. Откройте терминал в папке проекта (`/Users/pegasus/Desktop/DocScan`) и выполните две команды, подставив свой логин:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/docscan.git
```

```bash
git push -u origin main
```

Если терминал спросит логин и пароль — вместо пароля нужен токен GitHub: [github.com/settings/tokens](https://github.com/settings/tokens) → **Generate new token (classic)** → отметьте `repo` → скопируйте токен и вставьте вместо пароля.

### Шаг 2. Создайте проект на Railway

1. Зайдите на [railway.com](https://railway.com) и войдите через **Login with GitHub**.
2. Нажмите **New Project** (или **+ New** в правом верхнем углу).
3. Выберите **Deploy from GitHub repo**.
4. Если Railway попросит доступ к репозиториям — нажмите **Configure GitHub App** и разрешите доступ к репозиторию `docscan`.
5. Выберите в списке `docscan` и нажмите **Deploy Now**.

Railway найдёт `Dockerfile` и начнёт сборку сам.

### Шаг 3. Дождитесь сборки

1. Нажмите на появившийся блок сервиса `docscan`.
2. Откройте вкладку **Deployments** — там видно, как идёт сборка.
3. Первая сборка занимает **3–6 минут**: скачиваются зависимости и модели распознавания (~40 МБ).
4. Когда статус станет зелёным **Success** / **Active** — сайт запущен.

### Шаг 4. Получите ссылку на сайт

1. В сервисе `docscan` откройте вкладку **Settings**.
2. Найдите раздел **Networking** → **Public Networking**.
3. Нажмите **Generate Domain**.
4. Если Railway спросит порт — введите `8080` и подтвердите.
5. Появится ссылка вида `docscan-production.up.railway.app`. Откройте её — это ваш сайт.

### Как обновлять сайт

Сделали изменения в коде → закоммитили → выполнили:

```bash
git push
```

Railway сам пересоберёт и обновит сайт за несколько минут.

## Способ 2. Из терминала, без GitHub

Railway CLI уже установлен на этом маке.

1. Откройте терминал в папке проекта и войдите в Railway (откроется браузер, подтвердите вход):

```bash
railway login
```

2. Создайте проект (придумайте имя, например `docscan`):

```bash
railway init
```

3. Отправьте проект на сборку и запуск:

```bash
railway up
```

Команда покажет лог сборки. Первая сборка — 3–6 минут. Дождитесь сообщения об успешном деплое.

4. Создайте публичную ссылку:

```bash
railway domain
```

Команда выведет адрес сайта.

Чтобы обновить сайт после изменений — снова выполните `railway up`.

---

## Свой домен (по желанию)

Если хотите адрес вроде `docscan.вашсайт.ru`:

1. В Railway: сервис `docscan` → **Settings** → **Networking** → **Custom Domain** → введите домен.
2. Railway покажет запись **CNAME**. Добавьте её у регистратора домена (там, где покупали домен), в разделе DNS.
3. Через 5–30 минут домен заработает, HTTPS-сертификат Railway выпустит сам.

## Как проверить, что всё работает

1. Откройте ссылку на сайт.
2. Перетащите фото паспорта (JPG, PNG, WebP или HEIC) на плитку слева.
3. Первое распознавание дольше обычного (до минуты): браузер скачивает модели. Дальше — несколько секунд.
4. Поля справа заполнятся, бейджи покажут `MRZ` / `проверьте` / `вручную`.
5. Нажмите **«Одобрить и сформировать PDF»** — появится предпросмотр и кнопка **«Скачать PDF»**.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| Сборка упала на шаге `fetch_assets.sh` | Временно недоступен Hugging Face или jsDelivr, откуда качаются модели. В Railway: **Deployments** → три точки у упавшей сборки → **Redeploy**. |
| Сборка упала на `npm ci` | Проверьте, что в GitHub попал файл `package-lock.json` (он должен быть в репозитории). |
| Сайт открывается, но «Распознавание не запустилось» | Откройте сайт в Chrome или Safari последней версии; обновите страницу с очисткой кэша (Cmd+Shift+R). |
| **Application failed to respond** | Порт сайта и порт домена не совпали. Во вкладке **Variables** нажмите **New Variable**, имя `PORT`, значение `8080`, сохраните (Railway пересоберёт сайт). Затем в **Settings → Networking** проверьте, что у домена указан порт `8080`. |
| Нет кнопки **Generate Domain** | Дождитесь, пока первая сборка станет **Active** — кнопка появляется после успешного запуска. |

## Сколько это стоит

Сайт статический и почти не нагружает сервер: хватает минимальных ресурсов. На бесплатном пробном периоде Railway даёт стартовый кредит; дальше — тариф Hobby (около $5 в месяц, в него входит использование ресурсов на эту сумму). Актуальные цены — на [railway.com/pricing](https://railway.com/pricing).
